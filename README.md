## 貸出機管理
「🔁 貸出機管理」で19件の初期データを管理できます。ステータス、貸出ID、貸出先、貸出開始、返却予定、保守期限、組込み済モジュール、備考を変更できます。

貸出機データと貸出履歴は、ケース情報と一緒に「💾 JSON管理」の全データJSONへ保存されます。以前のJSONを読み込んだ場合も、貸出機データがなければ初期データが自動追加されます。
